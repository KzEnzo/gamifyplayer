## Problem

You have **one night** before stash rules compress and you do not want to vendor rare mats by accident.

## What we verified

Checked on **Steam PC** with default sort + manual filters. NetEase client uses the same stack rules but different UI fonts — labels read narrower; zoom UI once if unsure.

## Steps

1. Lock **two** tabs as “do not touch” using in-game favorites (not vendor lock — that expires).
2. Move all **blueprint-only** mats to tab 3; move consumables to tab 1.
3. Run one **public event** to flush mail attachments before purge (known mail overflow bug).

## Failure modes

If the vendor screen shows duplicate icons, **do not mass-sell** — relog first.
